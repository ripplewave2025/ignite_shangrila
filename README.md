# Ignite by Shangri-La — Saturday concept

This is a local, client-safe website prototype prepared for a discovery visit. It is not an official Ignite website and has not been deployed.

## What works

- Responsive home page with events, guest-list, table and private-event journeys.
- Reservation dialog with required service-contact permission.
- `Ignite Inner Circle` preference and consent demonstration.
- Optional music tastes and song/artist request field.
- Plain-language privacy concept.
- Keyboard focus, reduced-motion support and mobile navigation.
- Prototype forms deliberately do not send or store data.

## Open locally

From this folder:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Confirm on Saturday before publication

- Official public brand name and legal/license-holder name.
- Relationship between Ignite, Shangri-La Fine Dine, AIR Cafe and any hotel pages.
- Correct floor, address, Google map pin, official phone and WhatsApp.
- Day-by-day opening hours and event-night exceptions.
- Age, ID, dress, entry, cover, deposit, cancellation and table-release rules.
- Venue capacity, zones, accessibility, arrival and safety information.
- Approved menu, event details, logo, photographs and videos.
- Reservation owner, response target and escalation process.
- Privacy contact, guest-data system, retention period and opt-out process.

## Before going live

1. Replace `assets/ignite-concept-hero.png` with an approved real venue photograph. The current file is a generated concept, not a photograph of Ignite.
2. Replace all `Confirm Saturday` content with owner-approved facts.
3. Connect forms to an owner-controlled reservation/CRM system with role-based access and 2FA.
4. Add channel-specific consent records, unsubscribe/preferences and deletion handling.
5. Review the privacy notice and messaging flows with an appropriate Indian compliance professional.
6. Test every link, event page, form, analytics event and mobile layout.
7. Remove the `noindex,nofollow` meta tag only after the owner approves publication.
8. Add one unique page and valid `Event` structured data for each real event.

## Concept-image prompt

Generated with the built-in image-generation tool for a full-bleed website hero: a photorealistic, intimate Darjeeling hill-station music club with dark timber and stone, warm amber light, one restrained cyan beam, adult silhouettes, DJ to the right and negative space to the left. No logos, venue name, alcohol brands, embedded text or imitation of a specific real venue.
